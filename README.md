# 🧠 Merge Mind 2048

**Merge Mind 2048** is a fun and interactive number puzzle game where players combine matching number tiles to reach higher values and challenge their logical thinking.

## ✨ Features

- 🎮 Interactive number-merging gameplay
- 🧩 Brain-training puzzle challenges
- 🔢 Combine matching tiles to create larger numbers
- 🏆 Challenge yourself to achieve a high score
- ⚡ Smooth and responsive user interface
- 🌐 Play directly in your web browser

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

*Update this list if your project uses React, Vite, or other technologies.*

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/priyanshu-kumar-dev/merge-mind-2048.git
```

### 2. Navigate to the project directory

```bash
cd merge-mind-2048
```

### 3. Run the game

Open `index.html` in your web browser.

If the project uses a development server, start it using the commands configured in your project.

## 🎯 How to Play

1. Start the game.
2. Move the number tiles using the available controls.
3. Combine matching numbers to create larger tiles.
4. Keep merging tiles and try to achieve the highest score possible.

*Follow the controls displayed in the game.*
